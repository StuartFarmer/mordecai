P2P toolkit for a distributed world.

Software should give people the means to build and run things together. A community should be able to keep its conversations, markets, and games alive through the people who use them. Identity, payments, and distribution should be tools they can carry with them.

Mordecai exists to make that kind of software easier to build. It brings peer-to-peer networking, shared data, accounts, and programmable agreements into one toolkit. Developers can build applications whose participants help run the network, share its data, and verify its rules.

The idea is simple: keep everyday activity between the people involved, and use shared consensus where agreement matters. A conversation can travel directly between peers. A game can run among its players. Payments and ownership can settle on a common chain. Each part does the work it needs to do.

Mordecai is a work in progress. These demos are a place to try the tools, question the design, and help shape what comes next.
